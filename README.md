# CSE AI PRO ULTIMATE

📈 AI-powered Stock Analysis & Prediction Dashboard for Sri Lankan Stocks (CSE)  

**CSE AI PRO ULTIMATE** is a premium Streamlit application built by a 10-year Python dev expert.  
It allows traders and investors to visualize historical stock data, technical indicators, and AI-driven price forecasts for the Colombo Stock Exchange (CSE).

---

## Features

- Real-time stock data from Yahoo Finance (supports Sri Lankan stocks in format SYMBOL.N0000)
- Technical indicators:
  - RSI (Relative Strength Index)
  - MACD (Momentum Trend)
  - Moving Averages (MA20 & MA50)
  - Bollinger Bands
- AI Smart Forecast using **Random Forest Regressor** (predicts next 5 trading days)
- Colorful and responsive **premium dark theme** UI
- Price charts, volume charts, and technical oscillator charts
- Buy/Sell/Hold signals based on RSI, MACD, and moving averages
- Export analysis to CSV for further use
